# R10 global mechanism-stratified joint search

This continuation preserves the original single-`EXP_floor` Arrhenius family and the restored persistent/reversible current backend. It does not use independent temperature endpoints, guard/broad basis terms, empirical temperature laws, Paris-law production fits, source-density tuning, or event-law tuning.

## Broad analytical acquisition

The deterministic scrambled-Sobol bank contains 131,072 complete Family-A hypotheses generated by crossing the four original materials with the A/P25/P40/P55 design controls. All source barriers are exactly re-referenced to 300 K before crossing; this coordinate change preserves `G(T)` and `sigma_c(T)`. Transport enthalpy is shifted consistently with its retained activation entropy. Attempt frequencies, source geometry, and event law are fixed.

Of the bank, 70,986 rows satisfy the declared 300--1200 K positive-domain checks. The valid rows are divided into equal relative state-drive acquisition thirds (23,662 each), explicitly as selection strata rather than final mechanism labels. `state_reduction_allocation.csv` contains 4,096 stratified rows. The 48-row executable native registry is exactly balanced 16/16/16 across acquisition mechanism strata and 12 each across the four thermal proxies. Every selected row has a 300 K analytical ramp root between 2.39 and 32.30 MPa sqrt(m).

The A0 producer/consumer unit identity is closed explicitly: cooperative action/cycle is converted with `E[L]/E[Xi] = 5 um` for the unit-mean exponential action mark and mean-preserving threshold-correlated reward. No Family-B attenuation factor is used.
