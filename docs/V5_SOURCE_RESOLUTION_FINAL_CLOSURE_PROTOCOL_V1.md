## Prospective source-transfer budgets

Design target: at most 5% multiplicative uncertainty in a localized,
constant-positive-rate first-passage waiting time due to numerical source
representation. This is a declared numerical-design target, not experimental
calibration and not a relaxation of the existing 1e-12 partition-time gate.
For preserved remaining hazard H, t = H/lambda. Therefore
`abs(log(lambda/lambda_ref)) <= log(1.05)` bounds both rate and waiting-time
ratios between 1/1.05 and 1.05. The total log budget is split equally between
recovery-vs-reference and successive quality-valid refinement comparisons;
each receives `log(1.05)/2`, so their multiplicative bounds compose to 1.05.

Require at each allocated comparison:

- tensor relative error <= existing 0.05;
- absolute effective barrier difference / kBT <= log(1.05)/2;
- absolute log-rate difference <= log(1.05)/2;
- localized waiting-time relative error <= sqrt(1.05)-1;
- total reference waiting-time relative error <= 0.05;
- exact candidate, cavity, boundary-site, normal/tangent convention, threshold,
  RNG and event-classification ownership; mesh-dependent source captures must
  identify their distinct geometries and common physical source provenance.

Barrier clamping/prefactors are evaluated through the existing rate law, not
assumed interchangeable with barrier difference. Zero/nonfinite/underflowed
reference rates cannot establish positive qualification: compare inactivity
classifications exactly, never divide by a zero/near-zero reference rate.
Log rates should be calculated in the existing law's stable log domain.
Qualification also requires global q >= 0.05, unchanged geometry/topology,
existing resolution screens, frozen equilibrium/energy/reaction/tensor gates,
Kirsch error <= 0.03, and manufactured/rotation/order recovery checks.
