# V5 causal-coupling audit

The campaign matrix perturbs tensor invariants, candidate normal, signed shear,
each birth-work coefficient, birth barrier, and candidate weight. The implemented
dependency is explicit: candidate weight multiplies only the birth clock;
stabilization, healing, and growth use raw solver-derived rates.

Multi-hit renewal advances the state-owned RNG once and draws one exponential
threshold. Zero cleavage drive fails closed. Ligament and downstream events use
the existing cleavage engine and positive hazard-derived dissipation. The child
front is introduced only inside the reserved downstream topology transaction.

Opening perturbations at the explicit cavity surface produced monotonically
increasing downstream cleavage rates. `r_tip` is not created until a sharp front
exists and is never identified with `R_void`.

The matrix is a causal software audit, not evidence that the uncalibrated rate
magnitudes describe a particular material.
