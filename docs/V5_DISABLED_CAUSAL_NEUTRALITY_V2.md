# Disabled-only future-causal neutrality V2

Historical raw full-state identity remains `FAIL_RETAINED`. V2 is a prospective
causal comparison and does not alter or relabel that result.

`FUTURE_CAUSAL_STATE_FINGERPRINT_V1` retains all mechanics arrays, physical
reaction and energy values, graph and support ownership, hazards, thresholds,
RNG, event counters, mesh/remesh state, source identity, and topology. It may
exclude only:

- the four recomputable solver residual/identity diagnostics declared in the
  implementation;
- empty stored boundary-certificate report extensions, while retaining all
  recomputed topology predicates and support fingerprints;
- the audit-only support `source_commit` label, while retaining configuration
  and physical-source fingerprints;
- historical absence versus explicit `None` for disabled `void_state`; a
  non-null void state is an error.

The four frozen histories are monotonic, fixed-mesh oblique,
checkpoint/restart, and unload/reload. Each historical/current worker executes
the same initial geometry/load transaction, checkpoints it, then completes one
real source-measured future threshold crossing and topology transaction from
both the direct and restored state. One crossing is the prospective requirement;
V1's extra demand for three crossings was not part of the scientific mission
and caused later unrelated no-drive/support failures after valid causal evidence
had already been obtained.

PASS requires, for every history:

- one identical selected future event and operation history;
- exact within-worker direct/restart replay;
- no execution failure;
- identical historical/current future-causal components and fingerprints before
  and after the crossing;
- therefore identical retained mechanics, physical reactions and energies,
  hazards, thresholds, RNG, selected event, remesh decision, and topology.

Raw normalized states, raw differences, excluded-field values, consumer search
results, and the historical raw failure remain beside the causal decision. Any
new field difference, nonempty certificate difference, physical energy/reaction
difference, or enabled void state fails V2.
