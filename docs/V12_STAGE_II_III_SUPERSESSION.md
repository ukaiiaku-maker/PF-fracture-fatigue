## Evidence rule

A later gate may pass only from runner-generated case rows containing actual
initial/final fingerprints, executed operations, numerical observables, and
direct comparisons. A test return code, case-name inventory, manually changed
counter, stored-energy lambda, zero-array remesh initialization, or early
failure-stage return is insufficient.
