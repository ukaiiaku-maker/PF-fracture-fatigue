# Actual source-resolution guard and production transfer

Policy C is enforced in `_complete_next_clock` before any cavity-owned hazard
advance or proposal creation. The implementation currently has no qualified
production transfer certificate, so positive-drive cavity clocks are denied
with `UNQUALIFIED_CAVITY_SOURCE_TENSOR`. Raw existing-law rates remain available
as read-only diagnostics. The connected phase, complete candidate inventory,
hazards, thresholds, RNG, topology, and graph are retained. A source-kind
argument or caller-authored PASS flag cannot bypass the owned-state check.

All-zero drive remains physical dormancy, not rejection of an accepted
connection. Its time interval advances without advancing hazards and without
erasing stored source/candidate provenance. The default deterministic trajectory
now terminates at an unavailable first passage, not a fictitious child.

This intentionally revokes prior coarse-mesh downstream event claims. The
eleven retained tests in test_voiding_v5.py that require such events currently
fail. They are not marked inherited failures, weakened, skipped, or converted
to scientific passes. New guard regressions separately exercise the accepted
connection, partitioned no-advance, checkpoint/restart, and spoofing rejection.

Production transfer executes resolutions 32/12, 64/24, 128/48 and a 512/192
matched production reference with the same fixed crack. Each uses actual site
history, promotion, resolved growth, and ligament trial, then records all
actual source-native candidates, tensors, hazards, barriers and raw rates.
Checkpoint captures retain every accepted source state. Failures are retained.

The accepted static traction reference is NOT physically matched to production:
production includes plastic history, its own material, resolved radius growth,
and a different crack path. It cannot serve as a numerical production tensor
reference. A separate fine production reference is therefore attempted.

The frozen schema defines a 0.05 tensor limit and a 1e-12 transition partition
time limit, but no barrier/rate MESH-transfer error tolerances. Diagnostic
errors are reported without inventing or borrowing a scientific limit. No
production source is authorized until that complete prerequisite is met.
