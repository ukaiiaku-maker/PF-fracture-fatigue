# Genuine Kirsch FEM fine-family extension V1

Prospectively add 256/96 and 512/192 to the same exact annular Dirichlet problem,
without changing V1 recovery or the 0.03 accuracy limit. This is authorized by the
root mission's predeclared fine levels. Retain the initial three-level sentinel's
128/48 error 0.051074395084339294 as FAIL; never relabel that original result.

The new fine-family criterion requires both additional levels to have global
quality >=0.05, final tensor error <=0.03, strictly decreasing error between these
two levels, and exact A/B reproduction. It does not make any production source,
barrier, rate, timing or child-event claim. Original coarse failures remain part
of convergence evidence. All stored raw FEM inputs, stiffness, displacement and
stress must remain available for independent reconstruction.
