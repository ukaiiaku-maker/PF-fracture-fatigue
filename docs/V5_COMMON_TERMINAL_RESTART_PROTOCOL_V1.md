# Common-terminal restart load protocol V1

Prospective correction before executing the replacement restart histories.
The retained a34cdf0 restart matrix reloads only its zero-drive case to 8e-7 m,
while other checkpoints retain 4e-7 m. Those are different physical histories
and cannot be required to have one identical complete final state.

The replacement eleven-checkpoint reference has one load history: the existing
4e-7 m production prefix, accepted ligament connection, accepted -4e-7 m opening,
one 16-microsecond dormant interval, then the existing 8e-7 m tensile reload.
Source qualification, actual downstream first passage and one ordinary child
continuation follow at that reloaded state. The zero-drive checkpoint is taken
after accepting the compressive opening and before its dormant interval. All checkpoints
resume this same protocol, including its accepted protocol-position field.
That field is checkpointed and included in the full fingerprint. No accepted
interval, load stage, source proof, hazard, threshold, RNG or event is erased.

An inexpensive implementation check rejected the initial zero-opening proposal:
the retained plastic field leaves positive residual cleavage drive at that
opening. Zero nominal load is therefore not relabeled zero kinetic drive. The
fixed -4e-7 m value comes from the existing compressive/healing load protocol.
Every candidate must independently measure zero instantaneous rate at this
load, or the dormant reference fails without advancing any event.

The fixed values already occur in the preceding lifecycle protocols; this
change applies them consistently to the common reference. It does not change
source qualification, cleavage, geometry, energy, topology or any tolerance.
If the reloaded source fails qualification, that is a failed common-terminal
attempt, not permission to bypass its guard. The normal production source pair
and 45 transition matrix keep their own existing 4e-7 m histories. Natural
seeds retain their frozen window and load. Lifecycle evidence is versioned /6
to distinguish this replacement reference from retained /5 rows.
