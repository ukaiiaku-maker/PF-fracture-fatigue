## How the figures were made

Main-text and SI figures are generated by `05_PLOTTING_SCRIPTS/plot_fig{1..7}.py`
and `plot_si_figures.py`, reading **only** the committed, portable evidence
bundle (`source_bundle_figures_2_4/` on the independent-verifier branch) —
no mutable raw run directory was used. Part X figures are **reused**, not
regenerated with new physics: the branch's own existing, already-tracked
plotting scripts were re-run once (with a save-format patch only, adding
PDF/SVG export alongside the existing PNG) in a detached, read-only,
discarded worktree, so every Part X figure is byte-for-byte the same
scientific content as the accepted branch, just also exported as vector
graphics at 600 DPI raster.

Run order to reproduce from scratch:
```
cd 05_PLOTTING_SCRIPTS
<conda env with pandas/scipy/matplotlib> plot_fig1.py
... plot_fig2.py ... plot_fig7.py
... plot_si_figures.py
python3 build_manifests_and_qc.py
<conda env> build_combined_pdfs.py
```
(Part X figures are not regenerated by any script in this directory — see
`06_CAPTIONS_AND_NOTES/figure_scientific_notes.md` for how they were
produced and where.)

## Style

One shared style module (`05_PLOTTING_SCRIPTS/style_common.py`): white
background, no gridlines (except heatmap cell boundaries), sans-serif font,
outward ticks, no top/right spine, vector text in PDF/SVG
(`pdf.fonttype=42`, `svg.fonttype=none`), consistent 4-class and 6-system
color/marker mappings used identically across every figure, and journal-
scale figure dimensions (single-column ≈85 mm, double-column ≈175-180 mm)
rendered on a 2× working canvas so exported text reduces to ~9 pt at final
placed size.

## Required manuscript corrections (applied throughout)

1. Cramér's V is reported as a non-negative magnitude only (Figure 6A);
   association direction is stated in words, never as a negative value.
2. Figure 5D reports no cross-image magnitude ratio (the earlier "160×/
   1000×" claim is retracted as an unverifiable color-bar estimate); only
   the qualitative broad/diffuse-vs-narrow/localized comparison is retained.
3. Figure 4 uses "FEM/CZM shows no resolved local maximum on the available
   temperature grid" rather than a quantitatively established "muted
   shoulder."
4. Figure 5B states explicitly that geometrical path deflection is
   qualitative/unverified; only the orientation-dependent growth-RATE
   result is quantitatively verified.

See `06_CAPTIONS_AND_NOTES/manuscript_corrections.md` for the full text.
