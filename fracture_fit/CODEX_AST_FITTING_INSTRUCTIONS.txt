3. PHYSICS THAT MUST REMAIN COMMON

Use one material parameter vector across all temperatures, rates and observable
types. Use the same vector for initial 1-D confirmation. Geometry and legitimate
measurement origins may be specimen inputs/nuisance parameters; no separate
barrier, arbitrary toughness offset or hidden rate multiplier for every curve.

The selected pair uses four EXP-floor barrier surfaces: cleavage, emission,
Peierls motion and Taylor release. At nonnegative physical stress sigma:

  A(T) = G00 + gT*(T-Tref)
  c(T) = sigc0 + sT*(T-Tref)
  G*(sigma,T) = F(T) + [A(T)-F(T)] exp[-exp_a*(sigma/c(T))^exp_n]
  lambda = nu0 exp[-G*/(kB*T)]

Use the source's exact piecewise floor F(T), positivity guards and eV/J
conversion, specified in the model reference. Tref defaults to 481.33 K.
G00_eV is a reference free-energy barrier, not zero-temperature enthalpy.
PTMechanism.H0_eV also fills that reference-free-energy slot despite its name.
Do not add -sigma*V or an extra entropy exponential to this existing G*.

The native pair shares these elementary surfaces but has explicit reduction
differences. The 0-D Peierls/Taylor updates use forward elementary rates. The
inherited 1-D implementation uses a signed forward-minus-reverse combination,
lambda(max(tau,0))-lambda(max(-tau,0)), and clips Taylor release nonnegative.
Spatial transport, signed shielding and state translation also differ from the
mean-field reduction. Preserve and quantify these differences at matched
parameters; do not assume that shared surfaces guarantee identical kinetics.

The persistent source state, density-dependent front width, accumulated-slip
blunting, implicit backstress-limited emission, Peierls encounters, Taylor
release, multi-hit cleavage clock and translation convention remain active.
The selected persistent v9.13 contract has no source depletion, no source
refresh on advance and no explicit recovery. Do not optimize inactive inherited
fields or introduce extra mechanisms solely to improve an experimental fit.

Keep physical normalization explicit: source area/multiplicity, activation to
line-content conversion, b, slip orientation, density units, front width,
process-zone size and event advance. These affect effective rates; they are
not interchangeable optimizer knobs. Historical parameter sets are initial
guesses, not established tungsten calibrations.

4.1 Geometry and displacement control

Use Ast geometry inputs, not the archived calibration geometry. Nominal B=4 um,
W=6 um, specimen length 15 um; L lies 11-14 um, initial notch a0 lies 2-2.5 um.
The notch radius is not supplied. E(T) and nu(T) are in Table 1. Read the exact
metadata, use SI internally, and report all assumed/measured geometry fields.
Do not treat a guessed radius as a measured quantity or let an unrestricted
per-curve radius absorb barrier differences.
For the isotropic elastic convention used in the paper, also set the native
shear modulus G(T)=E(T)/[2*(1+nu(T))] consistently in each condition's physics.
Do not update the J conversion but inadvertently retain a different fixed shear
modulus in backstress. The historical b_m=2.74e-10 is an explicit model input;
retain its provenance and keep b out of the barrier optimizer.

For the published force normalization define, in SI units:
  f(x)=1.24+28.08*x-59.44*x^2+90.40*x^3
  kappa(a)=L*f(a/W)/(B*W^(3/2))
  K_el,current=F*kappa(a)
  K_nominal=F*kappa(a0)
The latter matches the Fig. 2 initial-crack normalization. Convert Pa sqrt(m)
to MPa sqrt(m) explicitly. Delta a=a-a0, never total a.

A practical fast mechanics implementation is a scalar cantilever reduction:
  u(t) = C_e(a,T)*F(t) + u_pl(z,a,T)
where z is the native state. Cache smooth geometry/compliance coefficients and
solve scalar force equilibrium at each accepted state update. Include any
fixed instrument compliance consistently, with its status as an assumption.
For a linear-elastic specimen segment, the consistency relation is
  dC_e/da = 2*B*kappa(a)^2/Eprime, Eprime=E/(1-nu^2).
This supplies an inexpensive compliance-increment check using the paper's
geometry factor. The initial notched compliance needs its own justified
beam/section calculation or constrained initial-slope estimate; do not infer
it by extrapolating the geometry polynomial beyond its valid notch range.

The plastic load-point displacement must come from the existing plastic-slip/
transport state through a documented beam/virtual-work or equivalent reduced
mechanical calculation. For example, a unit-force virtual-work projection
uses u_pl=integral(sigma_hat_unit_force:epsilon_pl dV), with consistent signs,
active volume and slip normalization. If an Orowan conversion is needed,
derive it from the same native mobile density, Burgers vector and transport
flux; identify this as a new observable closure and check its units/work.
Do not equate total emission count to global plastic displacement without that
mapping, fit an arbitrary u_pl function, or set u_pl=0 after yielding simply
to avoid the required mechanics.

The existing RCurveLoadingMap stores K/U coefficients. It is sufficient only
where the stated linear mechanical relation applies. With evolving u_pl,
introduce the minimal mechanical callback/outer solver needed to drive the
native state with the current force-derived loading. Retain the native

4.2 Evaluate the paper's observables

LEFM Kq: use the paper's 95% loading-line force construction, or maximum load
up to a physically predicted failure endpoint for a purely linear response,
with the initial notch geometry. A prescribed load ceiling, numerical timeout
or unfinished run does not define a predicted fracture toughness.

Basic-J at final cleavage:
  J_basic = K_el^2/Eprime + eta*A_pl/[B*(W-a)], eta=2.
Keep this observer distinct from the continuous method. Verify and explicitly
encode which crack length is used in its elastic K and ligament terms. The
accepted manuscript explicitly specifies initial a0 for LEFM and evolving a_i
for the continuous method, but its abbreviated basic-J equation uses a without
fully resolving that convention. Do not silently inherit the current-crack
observer. Record any unresolved convention as an assumption and assess its
sensitivity; use the paper's referenced method if accessible.

Continuous-J:
  J_pl,i = [J_pl,i-1 + eta*(A_pl,i-A_pl,i-1)/(B*(W-a_i-1))]
            *[1-(a_i-a_i-1)/(W-a_i-1)]
  J_i = K_el,current,i^2/Eprime + J_pl,i.

Match the force/crack-length and plastic-area conventions in Ast equations 1-6
(accepted PDF pages 7-8). Reconstruct A_pl from the predicted force-displacement
history and its elastic/unloading part according to that observation method.

work divided by crack advance, or arbitrary accumulated plastic-state scalar.
Check elastic and known-work limiting examples. Document observation sampling
and ensure it does not create a step-size-dependent J estimate.

Continuous-J onset is the predicted resistance-curve value at Delta a=0.2 um,
using a declared smooth-trend/crossing convention comparable to the authors'
fit, followed by Kq,J=sqrt(Eprime*Jq). It is not first emission, first yield,
first atomic opening or necessarily first discrete crack event.
Verify that the trajectory reaches the required extension before interpolation.
The native 1-D checkpoint_K helper clamps an out-of-range request to its final
K, whereas the 0-D helper returns NaN. Do not let that clamp create a fictitious
0.2 um onset for a truncated or physically terminated trajectory.
When K is MPa sqrt(m), E is GPa and J is N/m:
  J=1000*K^2*(1-nu^2)/E_GPa.
Do not compare J(meanK) to meanJ as if they were identical.

Final unstable cleavage must be a separate outcome of the modeled mechanical/

6. WORKING OBJECTIVE AND DEPENDENCE

The files do not supply a complete statistical covariance model. Use a
documented robust working composite objective, not a falsely precise likelihood.
The following is a proposed computational design, not a measured noise model:

  L(theta,eta) = sum_c W_c sum_f w_cf
                [sum_i q_cfi rho(r_cfi/s_cfi)] / [sum_i q_cfi]
                + documented nuisance regularization.

Here c is a condition/specimen group, f an observable family, q quadrature
weights over curve support, s fixed working scales, and rho a robust loss of
the standardized residual. Map this convention explicitly to an optimizer's
API (SciPy's loss function is specified in terms of squared residuals).
For each condition normalize the available family weights; choose and freeze
them before fitting. The objective must not grow merely because a raster line
was digitized more densely. Record residual costs by observable and condition.
Do not multiply unknown per-observable sample counts by the full table n.

Freeze the selected observation mask, quadrature denominators and residual
vector length before optimization. A candidate ending before observed support
must not improve its score by dropping unmatched points or renormalizing over
its surviving segment. Use a declared endpoint/domain-coverage contribution
for physical early termination and a separate failure status/penalty for
numerical failure. Do not extrapolate through a physical termination.
Unsupported-channel exclusions are determined by adapter capability before
fitting, not by how well a parameter candidate performs.

For J curves, use the extraction's increasing-J ordering. On a monotone modeled
loading segment, compare Delta a_model(J_i) with Delta a_i; otherwise use an
ordered parametric curve distance with x/y working scales. Do not interpolate
the noisy, negative and nonmonotone observed Delta a as if it were a clean time
axis. Preserve visible horizontal spans as extraction diagnostics, not hard
confidence bounds. Never turn plot truncation into a physical stopping event.

For Fig. 2 traces honor the extracted branch and fit_role fields. Fit supported
loading branches; do not treat graphical connector interiors across a cleavage
drop as time-resolved observations. Include unloading only if the mechanical
observer represents that protocol. Fig. 2a has horizontal display offsets and
supports a relative loading origin; Fig. 2b/c have numerical displacement axes.
Use only a justified, bounded origin nuisance where needed, never a free
horizontal stretch that changes the loading rate.

Possible declared starting scales are K: max(0.2 MPa sqrt(m), 5% of observed K),

Use each Table 1/Fig. 5 mean once in a selected source scenario. Min/max intervals

    Robust scipy.optimize.least_squares is appropriate for smooth residuals;
    use a derivative-free/global initializer where event boundaries make
    finite-difference derivatives unreliable. Verify best objectives with
    tighter integration/localization and common event sequences.
  * Warm-start FIGURE5_ALTERNATIVE from the TABLE_PRIMARY solutions, but retain
    some independent starts to avoid assuming both sources share one optimum.
  * Release additional P/T/state parameters in small meaningful groups if
    residual trends and sensitivities justify them. Do not free every inherited
    dataclass field at once. Finish with a joint optimization of the selected
    shared vector rather than separate permanent per-observable fits.

C. Information and sensitivity
  * Inspect scaled sensitivity singular values, correlated parameter
    combinations, multiple minima and bound hits.
  * Profile influential barrier parameters/combinations by reoptimizing the
    others. Use the fast model for the bulk of profiles and source/geometry/
    weight/event-convention sensitivity work. Label profile-cost intervals as
    sensitivity intervals unless a defensible probabilistic likelihood exists.
  * Check condition-level holdouts and all 629 J support points. Monte Carlo
    averaging, if needed, should be increased until its numerical fluctuation
    is smaller than the declared working tolerances, not until it creates
    artificial confidence from large sample counts.

D. 1-D confirmation at unchanged material parameters
  * First check the eight J-curve conditions plus (-90 C, 0.2), (0 C, 0.05),
    and (75 C, 1.6): 11 unique conditions spanning rates and response regimes.
  * Use identical geometry/protocol assumptions, physical event convention,
    common stochastic draws where applicable and the shared observer. Record
    native approximation differences; do not force the numerical state
    translation of 0-D and 1-D to be identical merely to improve agreement.
  * For the selected native 1-D transfer, explicitly serialize
      translation_mode='hazard_coupled'
      translation_action_exponent=0.95
    as documented in the matching calibration README. Its default exponent
    is 1.0; do not rely on that default. The 0-D translation remains its native
    mean-field approximation. This setting is historical transfer evidence,
    not a new Ast-fitted material parameter.
  * Evaluate the final retained fit across all 31 conditions with 1-D at least
    once at the declared representative event/statistic convention; reuse
    histories for every applicable observable. Where ensemble confirmation is
    necessary, expand selected representative conditions first.
  * Before comparing, declare a practical 0-D-to-1-D tolerance as a fraction of
    each working experimental tolerance. Compare both observed quantities
    and state mechanisms. A small total cost can conceal a systematic family
    mismatch. Report the paired residuals, not just an aggregate pass flag.

E. Local 1-D fallback when reduction error matters
  * If 1-D changes finalist rankings, response mechanisms or inferred barriers
    materially, retain the analytical result and use 1-D to refine influential
    parameters locally around the analytical candidate set.
  * A local discrepancy/surrogate correction may be trained on paired 0-D/1-D
    predictions within that parameter neighborhood. It must approximate the
    model difference, not fit an arbitrary temperature-dependent bias directly
    to experiments. Verify all final claims with direct 1-D calls.
  * Do not perform a global 1-D population search or escalate to 2-D. If the
    required observables cannot be reproduced in this model family, deliver
    the best fit, residual evidence and remaining identifiable barrier
    combinations; do not manufacture a successful fit by changing definitions.

Use parallel independent cases with bounded workers and avoid BLAS/thread
oversubscription. Checkpoint completed forward cases and optimizer states.
The template defaults to at most 8 workers and roughly 128 initial starts; adapt
search density to measured cost. Aim for a complete first result on a reasonable
workstation timescale, then spend effort on demonstrated remaining uncertainties.
Do not launch old hundred-thousand-candidate scripts or run every profile with
1-D. Reduce optional search/uncertainty density before sacrificing the primary
experimental grid, observation fidelity or final 1-D confirmation.

8. IMPLEMENTATION LAYOUT AND DELIVERABLES

Create a focused package such as experimental_fits/ast2018/ in the selected
repository, with new modules for dataset loading, parameter mapping, the
cantilever/observation adapter, residual construction, analytical optimization,
1-D confirmation, uncertainty and plotting. Exact new names are implementation
choices; the reference native entrypoints above are existing names.

Supply a documented single launcher for the complete campaign and separate
resume/analysis commands. Default to 2-D disabled and check this at runner entry.
The launcher must use the existing data, not search/redigitize it each time.
Do not alter historical simulations or global package defaults just to fit Ast.

Final outputs must include:
  * FIT_REPORT: what was fitted, selected model versions, observer equations,
    protocol/geometry/event assumptions, unsupported channels if any, and
    scientific conclusions from the fit.
  * Parameter tables with exact code keys, units, bounds, fixed/fitted/profiled
    status, source scenario and attempts/source-count conventions.
  * Fitted G*,H*,S*,V* and elementary/effective rates over the stress/T domain
    actually visited, with uncertainty/sensitivity and floor/cap indicators.
  * Predicted versus observed onset K and cleavage K against T for every rate,
    eight J curves, available nominal K/stiffness histories and outcome checks.
  * Analytical-versus-1-D overlays at unchanged parameters and any separate
    local 1-D-refined result; do not present refinement as original confirmation.
  * Residuals and cost contributions by condition/observable; source-alternative,
    geometry/radius, prefactor/source and weighting sensitivity tables.
  * Machine-readable predictions, resolved configuration, source commit/import
    receipt, runtime/call counts, seeds and a complete reproduction command.

Every subplot must have its own x-axis label. Use no grid lines and no large
plot titles above axes. Use legends or small internal panel annotations. Export
PNG plus vector PDF/SVG. Keep crack extension, nominal K, local drive K and
J-equivalent K labels unambiguous. Include familiar fracture observables in the
main figures; numerical imposed displacement is a supporting variable.

COMPLETION CRITERION

The task is complete when the joint analytical fit has been executed with
documented observation operators, both source scenarios have been assessed,
the final parameter inference has received direct 1-D confirmation/refinement,
and the full report/data/figures are delivered. A poor fit or a flat parameter
direction is a scientific result and should be reported honestly. A preflight,
one fitted curve, an onset-only fit labelled as a full R-curve fit, a fit to
synthetic class scores, or a silently rescaled surrogate is not completion.
